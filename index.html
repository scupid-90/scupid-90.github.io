Beyond Near-Perfect Accuracy: An Evaluation of Temporally Validated and Explainable Machine Learning for Mobile Money Fraud Detection

PROBLEM문제
Fraud models on mobile money data often report near-perfect scores. Those scores usually come from random train/test splits, which let a model learn from the future and overstate how it will perform once deployed.모바일 머니 데이터의 사기 탐지 모델은 종종 완벽에 가까운 점수를 보고합니다. 그러나 이 점수는 대개 무작위로 학습·테스트 데이터를 나눈 결과로, 모델이 미래 데이터를 미리 학습하게 되어 실제 운영 성능을 과대평가하게 됩니다.
WHAT I DID수행 내용
Benchmarked Logistic Regression, Random Forest, XGBoost and Isolation Forest on about 6.3 million PaySim transactions, across four ways of handling class imbalance (baseline, undersampling, SMOTE, class weighting). I re-tested every model on time-ordered splits, ran feature-ablation experiments, and used SHAP across several training seeds to explain each prediction.약 630만 건의 PaySim 거래 데이터로 Logistic Regression, Random Forest, XGBoost, Isolation Forest를 비교하고, 네 가지 클래스 불균형 처리 방식(기준, 언더샘플링, SMOTE, 클래스 가중치)을 적용했습니다. 모든 모델을 시간 순서 기반 분할로 다시 검증하고, 특성 제거(ablation) 실험을 수행했으며, 여러 학습 시드에 걸쳐 SHAP으로 각 예측의 근거를 설명했습니다.
RESULT결과
Showed that headline accuracy overstates real-world performance, identified which models stay reliable under time-ordered testing, and traced which account-balance features drive their decisions.겉으로 보이는 정확도가 실제 성능을 과대평가한다는 점을 보였고, 시간 순서 기반 검증에서도 신뢰할 수 있는 모델을 찾아냈으며, 어떤 계좌 잔액 관련 특성이 모델의 판단을 좌우하는지 규명했습니다.

Same candidate, different words: measuring bias in an LLM같은 지원자, 다른 표현: 대규모 언어모델(LLM)의 편향 측정

Same Candidate, Different Words: A Name-Substitution Framework for Measuring and Mitigating Racial and Gender Bias in Claude's Outputs

PROBLEM문제
Generative AI is used to write about people, but it is hard to tell whether its tone or judgement changes with a person's name.생성형 AI는 사람에 관한 글을 작성하는 데 쓰이지만, 이름에 따라 어조나 평가가 달라지는지 파악하기는 어렵습니다.
WHAT I DID수행 내용
Designed a name-substitution framework: identical prompts about the same candidate, with only the name changed to signal different racial and gender groups. I compared the outputs case by case and tested mitigation prompts in further rounds.이름 치환 프레임워크를 설계했습니다. 같은 지원자에 대한 동일한 프롬프트에서 인종과 성별을 나타내는 이름만 바꾸어 결과를 사례별로 비교했고, 이후 단계에서 편향 완화 프롬프트를 시험했습니다.
RESULT결과
A reusable, controlled method for measuring racial and gender bias in LLM outputs, published as a conference paper.LLM 출력물의 인종·성별 편향을 측정할 수 있는 재사용 가능한 통제 실험 방법을 만들어 학술대회 논문으로 게재했습니다.
